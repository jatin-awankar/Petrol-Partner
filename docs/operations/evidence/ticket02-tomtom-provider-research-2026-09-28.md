# Ticket 02: TomTom routing provider research (2026-09-28)

**Decision: not approved for real bookings.** This is a document review, not an account or API rehearsal. It establishes a plausible technical candidate but does not establish the licence needed to retain an auditable route snapshot or display it on the existing Mapbox map.

## Findings

- TomTom Maps Routing API v1 supports `car` and `motorcycle`; TomTom labels `motorcycle` **beta** and warns that full restriction data is unavailable in all areas. A route may include a section reported as `other` when the requested mode is unavailable. The documentation does not explicitly equate `motorcycle` with every scooter type, so scooter suitability needs TomTom confirmation and local route tests. [Calculate Route v1](https://docs.tomtom.com/routing-api/documentation/tomtom-maps/v1/calculate-route)
- TomTom lists India for Calculate Route and real-time traffic, but that table does not prove motorcycle restrictions and stopping-side accuracy on the intended roads. [Market coverage](https://docs.tomtom.com/routing-api/documentation/tomtom-maps/v1/product-information/market-coverage)
- The v1 API returns distance, duration, and route geometry, and supports distances at route polyline points. These are technically relevant to frozen route versions and segment pricing. The newer Orbis v3 docs describe route reconstruction from a GeoJSON path, but the reviewed v3 surface did not establish motorcycle mode. TomTom recommends Orbis for new integrations and warns that combining TomTom Maps and Orbis data can yield mismatched geometry. The candidate for two-wheelers is therefore specifically **TomTom Maps Routing v1**, subject to longevity and licence confirmation. [Calculate Route v1](https://docs.tomtom.com/routing-api/documentation/tomtom-maps/v1/calculate-route) · [Orbis Calculate Route v3](https://docs.tomtom.com/routing-api/documentation/tomtom-orbis-maps/v3/calculate-route) · [TomTom Orbis introduction](https://docs.tomtom.com/tomtom-orbis-maps/documentation/introduction)
- TomTom's current pricing page advertises **20,000 free Routing API requests per month** and no card needed to start. Its FAQ says commercial applications are allowed during free evaluation and requests return HTTP `429` after free limits or prepaid balance are exhausted. This supports a no-card synthetic test and a fail-closed quota design, but neither the published allowance nor `429` is an uptime guarantee or a promise that free terms will remain unchanged. [Pricing](https://docs.tomtom.com/pricing) · [Platform FAQ](https://docs.tomtom.com/platform/documentation/status-and-support/faqs)

## Unresolved licence and operational gates

1. **Durable storage:** The currently linked developer [terms page](https://docs.tomtom.com/legal/terms-and-conditions) did not expose its substantive licence text in the accessible official documentation reviewed. There is no established permission to retain v1 route geometry, point-level cumulative distances, and related provider output for the full booking/audit retention period. Do not infer permission from the API's ability to return that data. Obtain the applicable signed-in terms or written TomTom clarification, with the exact data fields and retention duration.
2. **Map display:** No reviewed official term established permission to overlay TomTom route geometry on the existing Mapbox base map. Confirm this with TomTom and check Mapbox's terms separately before using the combination; otherwise consider a TomTom display map only after its licence and cost are verified.
3. **Production and mode:** Clarify whether the free evaluation permits this specific ride-booking production use over time, whether motor scooters are covered by `motorcycle`, and the support/deprecation horizon of v1 beta motorcycle routing. The FAQ's general commercial-use answer alone does not settle these points.
4. **Rehearsal:** No TomTom account, card status, API key, calls, billing dashboard, or road-level results were inspected. In a synthetic no-card account, test car, motorcycle, and scooter-representative routes in India; inspect all `travelMode` sections; test ordered segment matching and quota `429`; measure consumption and verify that no charge or auto-upgrade can occur. Do not include credentials or personal journeys in evidence.

Keep each vehicle-category booking gate closed until its legal/display/retention questions and controlled rehearsal pass. Ticket 03's rate and external-permissibility review is separate.
