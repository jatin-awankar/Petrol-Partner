The narrowly scoped script `scripts/pilot-evidence-offsite-rehearsal.mjs` creates one synthetic PDF under a new `ticket07-synthetic/` key in the private staging `pilot-student-evidence` bucket. It reads the bytes from Supabase, encrypts them with AES-256-GCM, writes a versioned B2 object under a `ticket07synthetic/` prefix, reads that exact version back, verifies its checksum and authentication tag, deletes only its source synthetic object, restores the bytes to a second new synthetic key, checks the restored bytes and anonymous public access, then deletes the restored object. The encrypted B2 object remains for an independent readback. The output includes its exact key, version ID, checksums, timestamps, and access status, but no credentials or evidence content.
